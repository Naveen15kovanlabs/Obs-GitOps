# Observability & GitOps

A 6-week hands-on learning journey focused on mastering Grafana and Prometheus, building production-ready observability skills, learning Datadog, and managing infrastructure and monitoring through IaC, CI/CD, and GitOps.

## Overview

This repository documents my practical learning and implementation of modern observability and DevOps practices during my internship at Kovan Labs.

The learning journey follows a structured approach: first developing a strong foundation in Prometheus and Grafana, then exploring Datadog, and finally integrating infrastructure as code, CI/CD, and GitOps workflows.

The goal is to understand not only how to configure monitoring tools, but also how to troubleshoot incidents, interpret metrics and logs, automate deployments, and explain the concepts clearly.

## Learning Roadmap

| Week | Focus Area | Key Learning Objectives |
|---|---|---|
| Week 1 | Prometheus Fundamentals | Metrics, exporters, PromQL, scraping, and targets |
| Week 2 | Grafana & Alerting | Dashboards, visualizations, alert rules, and notifications |
| Week 3 | Observability Ecosystem | Logs, Loki, Alloy, LogQL, and incident troubleshooting |
| Week 4 | Datadog | Metrics, logs, dashboards, monitors, and platform comparison |
| Week 5 | IaC & CI/CD | Terraform, automated provisioning, and monitoring deployments |
| Week 6 | GitOps & Production Readiness | Declarative configuration, Git-based workflows, and operational practices |

Each directory contains practical implementations, configuration files, documentation, or learning exercises for the corresponding topic.

## Technologies & Tools

- **Monitoring:** Prometheus, Grafana
- **Metrics Collection:** Node Exporter
- **Logging:** Loki, Grafana Alloy, LogQL
- **Cloud:** AWS EC2
- **Containers:** Docker, Docker Compose
- **Observability Platform:** Datadog
- **Infrastructure as Code:** Terraform
- **CI/CD & GitOps:** GitHub Actions and Git-based deployment workflows

## Hands-on Learning

The repository includes practical exercises such as:

- Deploying Prometheus and Grafana on AWS EC2.
- Collecting infrastructure metrics using Node Exporter.
- Creating Grafana dashboards and monitoring system health.
- Configuring alert rules and testing notifications.
- Collecting and querying logs using Loki and LogQL.
- Performing incident drills to simulate failures, investigate alerts, and document root causes.
- Exploring Datadog monitoring and mapping its capabilities to the Prometheus and Grafana ecosystem.
- Automating infrastructure and monitoring configuration through Terraform, CI/CD, and GitOps.

## Learning Objectives

By the end of this journey, I aim to:

- Design and operate a practical observability stack.
- Write PromQL and LogQL queries to investigate system behavior.
- Build dashboards and actionable alerts.
- Troubleshoot monitoring and logging issues independently.
- Understand the differences between open-source observability tools and Datadog.
- Manage monitoring infrastructure using code and version control.
- Explain the implementation, architecture, and operational decisions through technical demonstrations.

## Progress Tracking

The learning journey is tracked through a structured 6-week workbook covering:

- Weekly learning objectives and demonstrations.
- Task acceptance criteria and implementation status.
- Incident drills and postmortems.
- Technical session preparation.
- Learning goals and reference materials.

Weekly demonstrations and practical exercises are used to validate understanding and reinforce hands-on experience.
