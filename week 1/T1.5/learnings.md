
# What I Learned

- Learned how Grafana Alloy collects Nginx access logs from multiple servers and sends them to Loki.
- Used server labels to identify and filter logs from each Nginx server.
- Practiced LogQL queries to check request activity, HTTP errors, and frequently requested paths.
- Built a Grafana dashboard to view log data in one place.
- Learned to generate test requests and verify that the logs reach Loki and appear in Grafana.
- Got more comfortable troubleshooting dashboard queries when panels showed no data.
